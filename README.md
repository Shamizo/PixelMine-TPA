# 这分支改了啥？  
- 修了 RTP 在 Folia 上抽风的问题  
- 加了 `/tphere`、`/tpaall`、`/back` 死后弹窗（感谢HuskHomes）  
- 支持从 HuskHomes（Sqlite H2）导数据过来 /tpa migrate
- 将yml存数据办法改为了SQLite(WAL) 
- 为每一个功能添加了一个禁用世界的配置选项
